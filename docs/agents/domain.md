# Domain documentation

Bondi is a single-context repository. Read root `GLOSSARY.md` and relevant
`docs/adr/` records when they exist. Their absence is normal: create them lazily
when actual terminology is resolved or a significant decision needs a record.
Use the glossary's canonical vocabulary and surface conflicts with accepted ADRs.
Keep glossary entries about domain meaning, with implementation guidance in
`docs/architecture.md`. The domain-modeling skill supplies formats when needed.
